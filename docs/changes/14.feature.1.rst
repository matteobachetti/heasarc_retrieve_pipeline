Add SVOM ECLAIRs and GRM retrieval from the French Science Center, through the SVOM team's own tools run in their environment (``SVOM_ECPI_PYTHON``): catalogue by ObsID, event files with every orbit, attitude and SAA file around each of them. GRM event files are also searched by time over the ObsID's ECLAIRs files, since a weeks-long ECLAIRs ObsID has its GRM files under other ObsIDs.
