The default barycentring engine changed from HEASOFT's ``barycorr`` to the ``barycenter`` package, which is now a required dependency (``barycenter>=1.0.0``), and ``prefect>3`` is now required. Barycentred times agree with the old tools to about 0.1 microseconds (see ``tools/barycenter_validation/``), except for Chandra, which moves from the DE405 to the DE430 ephemeris and shifts by about 1 microsecond. The previous engines remain selectable in the configuration.
